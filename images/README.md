## 上传方法
1. 打开 https://github.com/randomCLB/pet-quiz/tree/gh-pages/images
2. 点击 **"Add file"** → **"Upload files"**
3. 把20张图片拖进去，确保文件名一致
4. 点击 **"Commit changes"**
5. 刷新网站即可看到照片！
